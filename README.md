## CarDetector
This project can detect rules on the road in real-time. You can side your parameters of your road and based on them check cars on the rule. If they don't approved your rules. The program add the car in inclusive json file, with number of this car, speed and rules what the car don't approved.

## Programming languages
This program was written on C++ and Python. C++ for opencv detect and Python for written information in json files.
